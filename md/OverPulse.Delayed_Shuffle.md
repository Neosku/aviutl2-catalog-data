## readme

テキスト登場時にランダムな文字を設定時間中に変化させ続けます。
設定項目多そうに見えると思うんですが、ただつけて漢字を制限するだけで思ったより良くなるはずです。

ただし1フレームごとに文字が変わるので、60fpsだと早いかもしれません
これを期に24fps教に入信しません？
(対応はできればするつもりですが、順に適用を有効化した後に同じ文字を連続して書いておけば応急処置は可能です。例 7{ああいいうう})

### 基本設定

- **ランダムF**
　　文字が変わり続ける時間をフレーム単位で指定します。
- **個別指定**
　　├ランダムFで設定
　　│　一つ上のランダムFのみで設定します。DelayはランダムFと同じ値になります。
　　├ランダムF個別
　　│　ランダムFを文字ごとに指定できます。DelayはランダムFと同じ値になります。
　　├Delayのみ個別
　　│　ランダムFは共通で設定しますが、DelayはDelay個別で記述します。
　　└ランダムF＋Delay
　　　　どちらも個別に設定します。
- **ランダムF個別**
　　個別指定で ランダムF個別・ランダムF＋Delay を選択した場合に使用します。
　　3*2で3,3,3と入力したのと同じ扱いになります。
　　また、文字数に対して値が足りない場合は、最後の値を連続して使用します。
- **Delay個別**
　　個別指定で Delayのみ個別・ランダムF＋Delay を選択した場合に使用します。
　　3*2で3,3,3と入力したのと同じ扱いになります。
　　また、文字数に対して値が足りない場合は、最後の値を連続して使用します。

### 使用文字

- **使用文字(共通)**
　　全文字共通で使用する文字を設定できます。
　　例 あア亜いイ伊 だとこれら6文字のなかでランダムに選出されます。
　　また、3文字目にだけ適用したい！という場合は
　　例 3{あア亜いイ伊}で3文字目のみこれら6文字のなかで選出されます。
　　例 3{あア亜いイ伊}7{うウ宇えエ江}のように複数の文字に対して設定が可能です。
- **ランダムシード**
　　値を動かすことで別のランダムな文字に変えられます。
　　使用文字で文字が設定されている場合は順番が変わります。
- 漢字を小1漢字のみに制限
　　ランダムに文字を選出する過程で、フォントが対応していない漢字が高確率で出てきます。
　　そのときはこちらの設定をオンにする、あるいは後述の使用文字漢字にて設定してあげてください。
- **順に適用**
　　使用文字にて文字を指定していた場合にのみ、文字の順番をランダムから記述の順番に変更します。
　　文字数がランダムFに対して足りなければ、文字数がなくなった時点でこれまでの文字からランダムに選出します。
- **文字設定方式**
　　├文字系統ランダム・共通設定・個別に文字を設定
　　│　使用文字などの設定を使用します。
　　└完全ランダム
　　　　なにが入力されていようとランダムです。
　　　　ただし漢字は小1漢字までに制限されています。

### 使用文字オプション

- **使用文字(ひら)**
　　使用文字(共通)をひらがなのみに限定したものです。
　　3{あいう}なども使えますが、ひらがな以外の文字に設定しても適用はされません。
- **使用文字(カナ)**
　　使用文字(ひら)のカタカナ版です。
- **使用文字(漢字)**
　　使用文字(ひら)の漢字版です。
- **使用文字(英字)**
　　使用文字(ひら)の英数字版です。
- **使用文字(他)**
　　使用文字(ひら)の記号やその他未分類の文字版です。

### 縦書き補正

- **Y座標ズレ補正**
　　縦書き時にY座標が本来の文字と少しズレてしまうため、それを補正する設定です。
- **縦書き回転文字**
　　描画の仕様上、横書きの文字をそれぞれの文字の座標に表示しています。
　　なので伸ばし棒などの横書き・縦書きで向きが変わる文字を指定して、向きを戻します。
　　記述は3文字目と5文字目、6文字目を指定したい場合、
　　例 3,5-6 のように指定が可能です。
　　(ぁぃぅなどの小さい文字は確認した限り大丈夫なようです。
　　一部のフォントは横書き・縦書きで少しだけ文字の形が変わるものがあります。)
- **X座標補正**
　　縦書き回転文字で指定した文字のX座標を補正します。
　　横書き文字を無理やり回転させているので、基本はズレます。
　　なのでこのスクリプトを無効化したテキストと並べて修正することをおすすめします。
- **Y座標補正**
　　X座標補正のY座標版です。
- **Z軸回転補正**
　　縦書き回転文字で指定した文字の角度を補正します。
　　大体4°くらい

### コマンド
ランダムF個別やディレイ個別、使用文字、縦書き回転文字
テキストボックスで使えるコマンド集です。

- **\*** (アスタリスク)
　　ランダムF個別とディレイ個別では、4*3を入力すると4,4,4のように、4が3回繰り返されます。
　　(文字数に対して指定された値が足りない場合、最後の値を連続させます。)
- **-** (ハイフン)
　　縦書き回転文字でのみ使えます。4-6と入力すると4,5,6の範囲指定が可能です。

- **n{}** (数字+ブレース)
　　使用文字でのみ使えます。4{あいう}と入力すると4文字目が「あいう」でランダム選出されます。
　　また、順に適用にチェックが入っていれば「あいう」の順番で登場しますが、もし文字数が足りなければ(この場合ランダムFが4以上なら)あとはランダムに選出されます。

- **対応記法**
ランダムF個別は\*コマンドのみ。
ディレイ個別は\*コマンドのみ。
使用文字はn{}コマンドのみ。
縦書き回転文字は-コマンドのみ。

### 注意

このスクリプトはランダムな文字の描画にAviUtl2の描画機能を別途使用しています。
(ランダム文字では新しくテキストオブジェクトを作り直しているとお考えください。)
そのため、制御文字環境下での動作が不安定になる場合があるほか、通常利用時にも描画位置、描画結果が意図しないものになる可能性があります。
改行に関しては極力デバッグをしていますが、多少バグの発生する可能性は上がります。
また、縦書きに関しても同様の理由で文字の位置、向き、形状などにズレが発生する場合があります。

バグ報告は*overpulse@proton.me*までお願いします。
