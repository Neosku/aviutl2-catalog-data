# シンプルレコーダー v0.2

AviUtl2 上でマイク音声を録音し、録音した WAV ファイルをタイムラインへ配置できるプラグインです。

## 主な機能

- マイク入力の録音（WAV / 16-bit ステレオ）
- 待機中・録音中の入力レベル表示
- 録音経過時間の表示
- 録音開始・停止に合わせた再生の連動
- 出力先フォルダーの選択・エクスプローラーでの表示
- 録音終了後のタイムラインへの自動配置
- 音量を 0～500% の範囲で調整

## インストール

`SimpleRecorder.aux2` を AviUtl2 の `Plugin` フォルダー（またはその直下のサブフォルダー）へ配置し、AviUtl2 を再起動してください。

起動後は、AviUtl2 の **表示** メニューから **シンプルレコーダー** を開けます。

## 使い方

1. 使用するマイクを選びます。
2. 必要に応じて音量、出力先、自動再生との連動を設定します。
3. **録音開始** を押すと録音を開始します。ボタン内に経過時間が表示されます。
4. もう一度ボタンを押すと録音を停止し、録音ファイルをタイムラインへ配置します。

出力先を指定していない場合は、保存済みプロジェクトと同じフォルダーが使用されます。どちらもない場合は録音を開始せず、保存先の指定を促す警告が表示されます。

## 注意事項

- 録音形式は現在 WAV のみです。
- マイクを他のアプリケーションが占有している場合、録音を開始できないことがあります。
