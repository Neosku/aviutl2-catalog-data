# Glitch_T

AviUtl ExEdit2 専用のグリッチエフェクトです。 デジタルスライス、色収差、V-HOLD、砂嵐ノイズ、走査線、ネオンカラーブロック帯などの本格的なグリッチエフェクトをHLSLで描画します。

---
## 導入方法

1. `Glitch_T.au2pkg.zip` を、AviUtl2 のプレビュー画面へドラッグ＆ドロップします。
2. オブジェクトの設定ダイアログの **[フィルタ効果の追加] ＞ [加工] ＞ Glitch_T** から適用できます。
---

## 設定項目一覧

### メイン設定

| 項目名 | 設定範囲 | 初期値 | 説明 |
| :--- | :---: | :---: | :--- |
| **強さ** (`intensity`) | 0 〜 100 | 50 | グリッチエフェクト全体の強さを調整します。 |
| **スライス高さ** (`slice_h`) | 1 〜 60 | 12 | 横分割スライスノイズの1行あたりのブロック高さを指定します。 |
| **RGBずれ** (`rgb_amt`) | 0 〜 150 | 30 | 色収差（R・G・Bの分離幅）のピクセル量を指定します。 |
| **速度** (`speed`) | 0 〜 30 | 5 | ノイズアニメーションの更新速度を調整します。（低い値でコマ送り感が出ます） |
| **縦ずれ量** (`v_shift`) | 0 〜 500 | 120 | 画面全体の上下ジャンプ・画面ロール（V-HOLD）の移動幅を調整します。 |
| **合成モード** (`blend_mode`) | 0 〜 4 | 0 | ノイズと元の画像の合成方式を選択します。<br>0: 通常 / 1: 加算 / 2: 乗算 / 3: オーバーレイ / 4: 差分 |

---

### 詳細設定

設定ダイアログの **「詳細設定」** を展開すると、バーで細かな調整が可能です。

| 項目名 | 設定範囲 | 初期値 | 説明 |
| :--- | :---: | :---: | :--- |
| **しきい値** (`threshold_val`) | 0 〜 100 | 50 | グリッチやスライスが発生する頻度の閾値を調整します。 |
| **ノイズ不透明度** (`noise_alpha_val`) | 0 〜 100 | 80 | 砂嵐・走査線・カラーブロックの不透明度（濃さ）を調整します。 |
| **砂嵐粒子サイズ** (`grain_size`) | 1 〜 20 | 2 | 砂嵐ノイズ粒子のドットピクセルサイズを指定します。 |
| **走査線密度** (`line_density`) | 1 〜 100 | 20 | 横帯状スキャンライン（走査線）ノイズの密度を調整します。 |
| **ノイズコントラスト** (`noise_contrast`)| 0 〜 100 | 60 | ノイズ粒子の明暗コントラスト・くっきり感を調整します。 |
| **シード値** (`seed_offset`) | 0 〜 100 | 0 | 乱数シード（ノイズのパターン）を変更します。 |
