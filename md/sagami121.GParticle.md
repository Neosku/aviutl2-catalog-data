# GParticle

Aviutl ExEdit2専用のパーティクルスクリプトです。

---

## 動作環境 

- **AviUtl ExEdit2 v2.1.9以降**
---

## 導入方法

1. Github Releaseから `GParticle.obj2`をダウンロードします。
2. `GParticle.obj2`を、Aviutl2のプレビュー画面へドラッグ＆ドロップします。
3. オブジェクトの「カスタムオブジェクト」から **`GParticle`** を選択してください。

---

## パラメータ説明

### 1. 発生量・寿命
| パラメータ | 初期値 | 範囲 | 説明 |
| :--- | :--- | :--- | :--- |
| **発生量** | `300` | 1 ～ 5000 | 画面内に生成される粒子の総数 |
| **寿命(秒)** | `3.0` | 0.1 ～ 20.0 | 粒子の発生から消滅までの時間 |
| **発生割合%** | `100` | 1 ～ 100 | 設定した発生量に対して実際に生成される粒子の割合 |

### 2. 発生源
| パラメータ | 初期値 | 範囲 | 説明 |
| :--- | :--- | :--- | :--- |
| **位置X / Y / Z** | `0` | -2000 ～ 2000 (Zは -10000 ～ 10000) | パーティクルの発生中心位置 |
| **範囲X / Y / Z** | `0` | 0 ～ 1000 | 発生源のランダムな広がり範囲 |

### 3. 物理運動
| パラメータ | 初期値 | 説明 |
| :--- | :--- | :--- |
| **アニメーション方式** | `全方向爆発` | `全方向爆発(0)` / `方向指定(1)` / `コーン状(2)` / `渦巻き/回転(3)` から選択 |
| **初速 / 速度分散%** | `150` / `20%` | 粒子の初期移動速度と、粒子ごとの速度のバラつき |
| **拡散角度** | `60` | 方向指定・コーン状選択時の噴射角 |
| **重力X / Y / Z** | `Y: 150` | 各軸方向にかかる重力加速度 |
| **空気抵抗** | `0.0` | 粒子の移動に対する減衰係数 |

### 4. 外観
| パラメータ | 初期値 | 説明 |
| :--- | :--- | :--- |
| **生成時 / 消滅時サイズ**| `20` / `2` | 発生時と消滅時の粒子直径 |
| **サイズ分散%** | `50%` | 粒子のサイズランダム度 |
| **拡大率** | `1.0` | 全体のスケール倍率 |
| **光の強さ** | `1.0` | 加算合成時などの輝度倍率 |
| **生成時 / 消滅時カラー**| `白` / `橙` | 時間経過に沿って変化するグラデーションカラー |
| **生成時 / 消滅時不透明度**| `100%` / `0%` | 時間経過に沿って変化する透過度 |
| **合成モード** | `通常` | `通常(0)` / `加算(1)` / `スクリーン(2)` / `乗算(3)` |
