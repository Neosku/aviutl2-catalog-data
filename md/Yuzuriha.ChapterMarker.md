# チャプターマーカー読み込み v0.1

MP4 ファイルに保存されたチャプター情報を読み取り、AviUtl2 のタイムライン上にある動画オブジェクトをチャプターごとの区間に分割するプラグインです。OBS などで作成したチャプター付き MP4 に対応しています。

## 主な機能

- MP4 コンテナに保存されたチャプターの開始時刻とタイトルを読み込み
- 選択中の動画オブジェクトをチャプター位置で自動分割
- 分割後の各オブジェクト名へチャプター名を設定
- 動画オブジェクトに設定済みのエフェクト・各種設定を維持して複製
- 実行結果を AviUtl2 の Undo 操作でまとめて元に戻すことが可能

## インストール

`AviUtl2_ChapterMaker.aux2` を AviUtl2 の `Plugin` フォルダー（またはその直下のサブフォルダー）へ配置し、AviUtl2 を再起動してください。

```text
C:\ProgramData\aviutl2\Plugin\AviUtl2_ChapterMaker.aux2
```

## 使い方

あらかじめ OBS の録画形式で **Hybrid MP4** を選択し、キーコンフィグからチャプターマーカーを付けて録画してください。チャプターマーカーに対応した録画フォーマットを選ぶ必要があります。

チャプターマーカーに名前を付けたい場合は、OBS プラグイン **StreamUP Chapter Marker Manager** の利用をおすすめします。

1. チャプターが埋め込まれた MP4 ファイルを AviUtl2 のタイムラインに配置します。
2. 分割したい動画オブジェクトを 1 つ選択します。
3. レイヤー編集上で右クリックし、**チャプターごとに分ける** を選びます。
4. 確認ダイアログで **OK** を押します。

選択したオブジェクトは、チャプターの開始位置ごとに分割された複数のオブジェクトに置き換わります。各区間には対応するチャプター名がオブジェクト名として設定されます。

チャプターが動画の先頭から始まらない場合、先頭から最初のチャプターまでの区間には、元のオブジェクト名（名前が空の場合は `(before first chapter)`）が設定されます。

## 付属コマンドラインツール

同梱の `AviUtl2_ChapterMaker.exe` に MP4 ファイルを渡すと、チャプターの開始時刻とタイトルを確認できます。

```text
AviUtl2_ChapterMaker.exe <input.mp4>
```

## 注意事項

- MP4 コンテナに保存されたチャプターのみを対象とします。チャプター情報のない動画は分割できません。
- タイムライン上で選択できる、単体かつ未編集のMP4 動画オブジェクトを対象としています。すでにカットされているオブジェクトやグループ化されたオブジェクト、複数オブジェクトを含むエイリアスは対象外です。
- 分割時は選択中のオブジェクトが置き換えられます。必要に応じて実行前にプロジェクトを保存してください。
