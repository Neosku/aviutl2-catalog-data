# 3DCG Movie Animation
AviUtl2に3DCG編集用のウィンドウと機能を追加します。

本プラグインは、Public Alpha版です。

## 使用方法
`表示` → `3DCG Movie Animation` を押してウィンドウを表示します。
ウィンドウの分離をすると非常にやりやすいです。

区分
- MOD

最低要件
- AviUtl2バージョン: v2.1.10
- OS: Windows 10 / 11
- GPU: Direct3D 11

依存プラグイン、追加のランタイムは不要です。

配布形式
- 公式サイト
- AviUtl2カタログ
