	テキストの見た目(フォント・色・文字装飾・縁取り/グラデーション等のフィルタ)をテンプレートとして登録し、タイムラインで選択したテキストへボタン1つで一括適用する汎用プラグインです。

## 特長
- 見た目を作り込んだテキストを選んで「選択から登録」するだけで、テキスト設定とフィルタ効果を丸ごとテンプレート化
- 単数・複数どちらの選択にも一括適用(テキスト以外は自動でスキップ)
- サイズ・拡大率/位置は、適用するかをチェックで都度選択(字幕の位置は保ったまま見た目だけ揃える、等)
- 「上書き」で、既存テンプレートを選択中テキストの今の見た目に更新
- 一覧の各行に「あAa漢」のプレビュー(多重縁取り・グラデーション・シャドーを近似表示)
- 適用は Ctrl+Z で元に戻せます

## 使い方
1. AviUtl2 のメニューに追加される「テキストテンプレ」ウィンドウを開きます(ドッキング可能)
2. 見た目を仕上げたテキストをタイムラインで選択し「選択から登録」
3. 揃えたいテキストを選択(Ctrl+クリックで複数可)→ 一覧でテンプレートを選んで「選択中に適用」(ダブルクリックでも可)

| ボタン | 動作 |
|---|---|
| 選択中に適用 | 選んだテンプレートを選択中のテキストへ適用 |
| 選択から登録 | 選択中テキストの見た目(フィルタ含む)を新規登録 |
| 上書き | 選んだテンプレートを選択中テキストの見た目で更新 |
| 新規 / 編集 / 削除 / ↑ / ↓ | 手入力作成・編集・削除・並べ替え |
| サイズ・拡大率も適用 | オン時のみサイズ・拡大率・縦横比を適用 |
| 位置も適用 | オン時のみ X/Y/Z・中心・回転を適用 |

## 注意
- 「既存フィルタを置き換える」がオンのテンプレートは、適用先の既存フィルタ(フェード等)を削除してから追加します
- プレビューは近似表示です
- テンプレートは Plugin\TextTemplate\templates.ini に保存されます(アンインストールしても残ります)
