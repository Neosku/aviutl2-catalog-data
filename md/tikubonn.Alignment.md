# 揃えスクリプト

オブジェクトの揃え位置を指定するスクリプトです。
本機能を利用することで、左上揃えのテキストオブジェクトを、画面中央にレイアウトするといったことができるようになります。

## 提供されるアニメーション効果

### 揃え@揃えv3

基本的な揃え機能を提供します。

#### パラメータ

- **揃え位置**
  オブジェクトの新たな配置基準となる位置です。
  中央を含む、上下左右斜めの計9つの位置を指定できます。

- **中心を変更する**
  効果適用後のオブジェクトの中心位置を変更するかどうかを指定します。
  本パラメータがオン状態ならば、効果適用後のオブジェクトの中心位置は、移動後オブジェクトの中心になります。

### 詳細揃え@揃えv3

X,Y軸の揃え位置を数値で指定する機能を提供します。
アニメーション機能などでゆっくり遷移させたい時に利用できます。

> [!NOTE]
> \[揃え\]効果と共通のパラメータは省略しています。

#### パラメータ

- **X,Y**
  X,Y軸の揃え位置を数値で指定します。
  本パラメータは -1.0 ~ 1.0 までの数値を指定できます。
  本パラメータはそれぞれ値が 1.0 に近ければ近いほど、オブジェクトは左・上揃えになり、
  逆に値が 1.0 に近ければ近いほど右・上揃えになります。

## 対応環境

- AviUtl ExEdit2 version 2.1.8

## Install

解凍された中にある "揃えv3" フォルダをそのまま "scripts" フォルダ内にコピーするだけです。
