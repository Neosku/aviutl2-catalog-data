## インストール
一般的なanm2スクリプトと同様に、AviUtl2本体へのドラッグ&ドロップ。
手動でインストールする場合、隠しファイルの表示をオンにしたうえで
C:\ProgramData\aviutl2\Script
にanm2ファイルをそのままコピペしてください(Scriptフォルダの中にさらにフォルダを作ってコピペしても大丈夫です)。

## readme
2点間の距離、X軸だけの距離、Y軸だけの距離、角度の4つを表示するカスタムオブジェクトです。

## 使用手順
タイムライン上で左クリック→メディアオブジェクトを追加→カスタムオブジェクト→ものさしスクリプト
の順で追加してください。
アンカーが3つ表示されます。

**1と表示されたアンカー**：距離や角度を測るアンカーの1つ目です。
角度ではこのアンカーを原点として計測します。

**2と表示されたアンカー**：距離や角度を測るアンカーの2つ目です。
角度ではこのアンカーを方向点として計測します。

**距離の情報が表示されているアンカー**：デフォルトでは2点間の距離のみ表示します
チェックボックスからX距離、Y距離、角度を追加できます。

## 使用上のTips
情報とアンカー番号の文字サイズを一括で調整できます。
また、情報がうまく表示されない場合はログ出力のチェックボックスを使ってください。
※ログ出力チェックボックスはオンでもオフでも、切り替えたタイミングでログを出力するボタンの挙動をします。
