
# ジグザグクリッピングスクリプト

画像の不透過部分に、ジグザグに切り取られたような背景を追加します。
背景の表示位置・大きさ・色・透明度などが設定できる他、専用のアニメーション機能も搭載されています。

## 提供されるアニメーション効果

### ジグザグクリッピング@ジグザグクリッピング

透過画像の不透過部分に、ジグザグに切り取られたような背景を追加します。

#### パラメータ

- **X,Y**
  背景の描画位置を設定できます。

- **余白**
  背景全体の追加余白量を設定できます。

- **ランダム余白**
  1アニメーション毎に変化する、背景全体の追加余白量を設定できます。

- **ランダム余白(個別)**
  1アニメーション毎に変化する、背景の各頂点毎の追加余白量を設定できます。

- **遷移時間,待機時間**
  1アニメーション毎の、遷移アニメーションの再生時間と、再生後の待機時間を設定できます。
  例えば、遷移時間=1,待機時間=2のように設定したならば、次のようにアニメーションが再生されます。

  ```
  | ttt------ | ttt------ | ttt...
  ```

  > [!NOTE]
  > "t"=遷移アニメーション,"-"=待機

- **しきい値**
  画像解析時に、その画素が不透過であるかを判定する際に使用される数値です。
  本パラメータは 0.0 ~ 100.0 までの数値を指定することができます。
  パラメータが低ければ低いほど、より低アルファ値の画素に対して反応するようになります。

- **分解能**
  画像解析時に、どれくらいの粒度で輪郭検出を行うかを設定できます。
  本パラメータは 8 以上の整数を指定することができます。
  パラメータが低ければ低いほど、より高精細な輪郭抽出が行えますが、その反面計算負荷が増加します。

- **透明度**
  背景の透明度を設定できます。
  本パラメータは 0.0 ~ 100.0 までの数値を指定できます。

- **背景色**
  背景の色を設定できます。

- **乱数シード**
  アニメーションで使用される乱数のシード値を設定できます。

### ジグザグクリッピング@ジグザグクリッピング(画像)

本効果も**ジグザグクリッピング**と同じく、オブジェクトに背景を追加しますが、単色ではなく、画像を使用することができます。

#### パラメータ

> [!NOTE]
> **ジグザグクリッピング**と共通のパラメータは省略

- **画像ファイル**
  背景に表示する画像ファイルを指定できます。
  ファイルが未指定の場合の動作は未定義です(開発者の環境では何も表示されませんでした)

- **背景X,背景Y**
  背景画像の表示位置を指定することができます。
  本パラメータは -1.0 ~ 1.0 までの数値を指定することができます。

  背景Xでは -1.0 ならば左に 1.0 ならば右に移動します。
  背景Yでは -1.0 ならば上に 1.0 ならば下に移動します。

- **背景拡大率,背景拡大率X,背景拡大率Y**
  背景画像の表示拡大率を指定することができます。
  本パラメータは 0.0 以上の数値を指定することができ 100.0 は原寸を表します。

## FAQ

- **バグ報告したいんだけど**
  親しい間柄でない限りバグ報告は受け付けておりません。
  それでも報告したい方はこれらの条件を読んだうえで報告してください。

  受け付けるバグの条件は次のとおりです。
  これらの条件を満たさないバグ報告は無視いたします。

  - 本スクリプトの最新版で発生したバグであること
  - 本スクリプトのみを導入した環境で再現できるバグであること
  - 本スクリプトの対応環境で発生したバグであること

  報告をする際には必ずこれらの情報を提供してください。
  
  - 具体的な症状
  - 発生する条件
  - 再現可能なプロジェクトファイル(外部ファイルを参照せずに、図形オブジェクトを使用したもの)
  - 使用している AviUtl, 拡張編集 のバージョン

  連絡先: [https://twitter.com/tikubonn](https://twitter.com/tikubonn)
