# DVD Bounce

`DVD.anm2` は、オブジェクトを画面内で跳ね返らせる AviUtl 2 用のアニメーション効果です。DVD プレーヤーの待機画面のような移動を、画像・動画・テキストなどに適用できます。

## 導入

1. `DVD.anm2` を AviUtl 2 の `Script` フォルダ、またはその1階層下に配置します。
   - 通常の配置先: `C:\ProgramData\aviutl2\Script`
2. AviUtl 2 を起動中に配置した場合は、スクリプトキャッシュを破棄するか、AviUtl 2 を再起動します。
3. オブジェクトの「アニメーション効果」から `DVD` を追加します。

## 設定項目

### 動作設定

| 項目 | 説明 | 初期値 |
| --- | --- | ---: |
| 速度 | 1秒あたりの移動量です。 | 400 |
| 移動角度 | 水平方向を 0° とした移動方向です。 | 45° |
| サイズ(%) | 移動させるオブジェクトのサイズです。 | 100 |
| 乱数シード | 開始位置を変更する値です。同じ値なら同じ開始位置になります。 | 0 |


### 領域設定

| 項目 | 説明 | 初期値 |
| --- | --- | ---: |
| 領域幅 | バウンスさせる領域の幅です。0 の場合は画面幅を使います。 | 0 |
| 領域高さ | バウンスさせる領域の高さです。0 の場合は画面高さを使います。 | 0 |

領域は画面の中央を基準に扱われます。オブジェクトが領域より大きい場合は、その軸の中央で停止します。

### 色設定

| 項目 | 説明 | 初期値 |
| --- | --- | ---: |
| 元の色を使用 | 有効にすると着色を行いません。 | 無効 |
| 彩度 | バウンス時に選ばれる色の彩度です。 | 80 |
| 明度 | バウンス時に選ばれる色の明度です。 | 100 |
| 着色強度(%) | 元の色と選択色を混ぜる割合です。 | 100 |
