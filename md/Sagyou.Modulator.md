# AviUtl2 Modulator

AviUtl2用のアニメーション効果およびスクリプトモジュールです。画像の各行または各列を走査し、輝度の累積値に応じて白線と黒線のパターンを描画します。

## 概要

AviUtl向けに公開されていた `Modulator.anm` および `Modulator.dll`（作成者: Aodaruma氏）を、AviUtl2向けにC++スクリプトモジュール（`.mod2`）として移植したものです。

### 機能説明
Modulatorは、走査方向に沿ってピクセルの輝度を累積し、その値が一定の閾値に達するごとに線を描画するエフェクトです。明暗の差に応じて線の密度が変化し、等高線やスキャン線のような縞模様を生成します。

各行および各列の処理は他の行や列に依存しないため、OpenMPによるマルチスレッド並列処理を適用しています。

## 導入方法

次のファイルをAviUtl2のスクリプトフォルダ（例: `C:\ProgramData\aviutl2\Script\` またはそのサブフォルダ）へ配置します。

- `Modulator.anm2`
- `Modulator.mod2`

配置後、AviUtl2のメニューから「キャッシュを破棄」を実行するか、AviUtl2を再起動してください。

## 使い方

1. 対象オブジェクトにアニメーション効果を追加します。
2. ドロップダウンリストから `Modulator` を選択します。
3. トラックバーや設定項目で線の太さや間隔を調整します。

### 設定項目一覧

| 項目 | 型・範囲 | 説明 |
| --- | --- | --- |
| スケール | 数値 | 輝度を累積する感度を指定します。値を大きくすると線の間隔が狭くなります。 |
| 描画数 | 整数 | 1つの線の束に含める線の本数を指定します。 |
| 間隔数 | 整数 | 線の束同士の間隔を指定します。 |
| 幅(px) | ピクセル | 描画する線の太さを指定します。 |
| 反転 | チェックボックス | 輝度の評価を反転します。有効にすると暗い部分で線が多く描画されます。 |
| 方向 | 選択 | 走査する方向を指定します（0: 左から右、1: 右から左、2: 上から下、3: 下から上）。 |
| 閾値 | 数値 | 線を描画する判定基準となる累積輝度の下限値を指定します。 |
| 透明度(白) | 0〜255 | 描画する白線の不透明度を指定します（0で完全透明、255で完全不透明）。 |
| 透明度(黒) | 0〜255 | 描画する黒線の不透明度を指定します（0で完全透明、255で完全不透明）。 |

## 処理の最適化

以下の手法で処理負荷を軽減しています。

- **1パス走査**: 各行または各列を1回のみ走査します。計算量は画像の総ピクセル数（幅 $\times$ 高さ）に比例し、追加で動的確保するメモリはありません。
- **マルチスレッド並列化**: 各行・各列の走査処理は独立しているため、OpenMP（`#pragma omp parallel for`）を用いてCPUの全論理コアで並列処理を実行します。
- **コンパイラ最適化**: 最適化オプション `/O2`（最大速度最適化）および `/Oi`（組み込み関数のインライン展開）を適用しています。
- **インプレース更新**: 画像データを別の作業用バッファへコピーせず、渡された画像バッファを直接書き換えます（ゼロコピー）。
- **定数事前計算**: 輝度積算の除算係数や線ピクセルの色値を走査ループ外で事前に計算し、ループ内の演算回数を減らしています。
