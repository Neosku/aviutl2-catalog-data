# Aviutl2-QRCode

QRコードの生成ができるスクリプトです。

---

## 導入方法

1. `QRCode.obj2` を、AviUtl2 のプレビュー画面へドラッグ＆ドロップします。
2. **[カスタムオブジェクト] ＞ QRコード** から適用できます。
---

# 設定項目一覧

| 項目名 | 設定範囲 | 初期値 | 説明 |
| :--- | :---: | :---: | :--- |
| **サイズ** (`track0`) | 1 〜 100 | 10 | ドットの基本サイズを指定します。 |
| **余白** (`track1`) | 0 〜 20 | 4 | QRコード周囲の余白の広さを指定します。 |
| **誤り訂正** (`track2`) | 0 〜 3 | 0 | データの誤り訂正レベルを選択します。<br>0: L / 1: M / 2: Q / 3: H |
| **形状** (`track3`) | 0 〜 2 | 0 | QRコードを構成するドットの形状を選択します。<br>0: 四角 / 1: 円 / 2: 角丸 |
| **テキスト** (`text`) | 任意文字列 | `https://example.com` | QRコードに埋め込むテキストやURLを指定します。 |
| **前景色** (`fg_col`) | カラー | `0x000000` | QRコードのドット部分の色を指定します。 |
| **背景色** (`bg_col`) | カラー | `0xffffff` | 背景の色を指定します。 |
| **背景透明** (`bg_trans`) | 0 〜 1 | 0 | 背景を透明にするかどうかを指定します。<br>0: オフ / 1: オン |
| **角丸強度** (`corner_r`) | 0 〜 50 | 30 | 形状で「角丸」を選択した際の丸みの強さを指定します。|
