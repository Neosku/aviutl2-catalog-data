# 機能
パーツ上書きを監視し、監視対象のパーツが変更された時に指定のアニメーションをしてもらうスクリプトです。  
表情変更ではアニメーションせず、腕を動かしたときにだけ跳ねるなどの指定ができます。

# 設定
PSDToolKitで読み込んだPSDにくっつけて使用します。  
キャラクターID、参照レイヤーを指定し、監視したいパーツを設定。  
パーツ上書きの番号、anm2エディタで作ったものであれば一番上が1です。  
あとは好みでアニメーションの設定を弄っておしまいです。

# そのほか
**パーツ上書きを1つのレイヤに隙間なく並べ、分割して使う**ことが前提になっています。  
隙間があると終端を上手くとれずにおかしな挙動になる可能性が高いです。

GitHubリポジトリに改変用ベース.anm2があります。  
中の指示に従えば簡単に独自アニメーションを追加することができると思います。
