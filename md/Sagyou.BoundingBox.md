# AviUtl2 BoundingBox

AviUtl2のオブジェクト画像から不透明ピクセルの範囲を検出し、その外接矩形（バウンディングボックス）を描画するスクリプトです。外枠線（ボーダー）の描画および背景矩形の塗りつぶしに対応します。

## 機能

オブジェクト画像のアルファ値（透明度情報）を走査して文字や図形が存在する最小の矩形領域を特定し、その領域に対して枠線描画や塗りつぶしを行います。

各設定項目の詳細は以下のとおりです。

- **しきい値（threshold）**: オブジェクトが存在すると判定するアルファ値の境界（0〜255）。この値以上のアルファ値を持つピクセルを基に外接矩形を計算します。
- **線の太さ（line_width）**: 枠線の太さをピクセル単位で指定（0〜100）。0を指定すると枠線を描画しません。
- **透明度（opacity）**: 描画するボックスの不透明度（0〜255）。255で完全不透明、0で完全透明になります。
- **背景塗りつぶし（fill）**: 有効にすると、外接矩形の内部全体を指定色と透明度で塗りつぶします。
- **文字を前面にする（text_front）**: 
  - 有効（1）: オブジェクトのピクセルを前面に配置し、ボックスを背面に描画します。
  - 無効（0）: ボックスをオブジェクトの前面に重ねて描画します。
- **透明度を2値化（binary）**: 有効にすると「透明度」の設定値を無視し、不透明度を 255（完全不透明）として処理します。
- **ボックスのみ（only）**: 元のオブジェクト画像を消去し、矩形ボックス（枠線または塗りつぶし）のみを出力します。
- **色（box_color）**: ボックスの描画色を指定します。

## 導入手順

1. `BoundingBox.anm2` および `BoundingBox.mod2` を AviUtl2 の `script` フォルダに配置します。
2. AviUtl2 を起動（または再起動）します。

## 使用手順

1. テキストオブジェクトを作成します。
2. テキストオブジェクトの描画設定で「個別オブジェクト」を有効にします。
3. フィルタ効果またはアニメーション効果として「Bounding Box」を追加します。
4. 目的に応じてパラメータを設定します。

### 設定例

- **文字の背後に背景矩形を配置する場合**:
  - `背景塗りつぶし`: 1（有効）
  - `文字を前面にする`: 1（有効）
  - `線の太さ`: 0（枠線なし）または任意の幅
  - `ボックスのみ`: 0（無効）
- **文字の周囲に枠線のみを描画する場合**:
  - `背景塗りつぶし`: 0（無効）
  - `文字を前面にする`: 1（有効）
  - `線の太さ`: 1以上の値
  - `ボックスのみ`: 0（無効）
- **文字の前面に枠線を重ねる場合**:
  - `文字を前面にする`: 0（無効）
  - `線の太さ`: 1以上の値
- **文字と同じサイズの矩形図形のみを取得する場合**:
  - `ボックスのみ`: 1（有効）
  - `背景塗りつぶし`: 1（矩形塗りつぶし）または 0（枠線のみ）
