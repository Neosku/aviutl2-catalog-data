==================================================
UTAU画面表示 for AviUtl ExEdit2
==================================================

UST / ustx ファイルを読み込み、UTAU または OpenUtau の編集画面
（ピアノロール）風の映像を表示するメディアオブジェクトです。
UST / oto.ini は Shift_JIS と UTF-8 のどちらも読めます（自動判別）。

※ 非公式の再実装です。UTAU・OpenUtau の各配布元とは関係ありません。


■ 使い方
--------------------------------------------------
1. オブジェクト追加メニューから「UTAU画面表示」を追加
2. 「ファイル」に .ust / .ustx を指定
3. 「スタイル」で UTAU / OpenUtau を選択
（ファイル形式とスタイルは自由に組み合わせ可）
4. UTAU スタイルでは必要に応じて「UTAUフォルダ」を指定（空欄なら自動検出）
5. お好みで「キャラクター画像」を指定


■ 設定項目
--------------------------------------------------
グループごとに分かれており、選んだスタイルで使わない項目は隠れます。
多くの項目で「0 / 空欄」は既定値を使う意味です。

◆ 基本
・ファイル ………… 表示する UST / ustx
・スタイル ………… UTAU / OpenUtau
・トラック ………… 表示するトラック番号（ustx のみ、1 始まり）

◆ 表示
・幅 / 高さ ……… 出力サイズ（0: シーンのサイズ）
・四分音符の幅 …… 1 拍の px（0: UTAU 64 / OpenUtau 128）
・半音の高さ ……… 1 行の px（0: UTAU 14 / OpenUtau 22）
・スライド表示 …… ON: 再生位置を中心にスクロール / OFF: ページ送り
・再生位置
スライド時 → 再生線の横ずらし(px)
ページ送り時 → ページ幅(px。0 以下は画面幅との差)
・縦位置
曲全体 → 音域の中央に固定（既定）
ノートに追従 → 再生位置付近のノートに合わせて動く
・追従の範囲 ……… 追従時に前後何秒のノートを見るか（既定 4 秒）
大きいほどゆっくり動く
・表示位置 ………… 縦位置からさらに縦にずらす量(px)
・背景透過 ………… 背景・鍵盤・ヘッダー・キャラクター画像を描かず、
ノートなどだけを出力
・フォント ………… 空欄: UTAU は MS UI Gothic / OpenUtau は Yu Gothic UI

◆ 時間
・時間基準 ………… オブジェクト / シーン の先頭を曲の先頭に合わせる
・時間オフセット … 表示時刻のずらし(秒)
・表示を固定 ……… 時間を進めず、時間オフセットの位置を表示し続ける

◆ ピッチ
・ピッチモード
自動 → #SETTING の Mode2 に従う（既定）
Mode1 → PitchBend / Mode2 → PBS・PBW・PBY・PBM
・ピッチ曲線を表示
UTAU → ノートを細いバーにしてエンベロープ・ピッチ・音量を表示
OpenUtau → ピッチ点の線を表示
・最終ピッチを表示 …（OpenUtau）音高・ピッチ点・ビブラート・pitd から
計算した線
・ビブラートを表示 …（OpenUtau）ビブラートの線

◆ キャラクター画像
背景とノートの間に画像を薄く重ねます。
（鍵盤・ヘッダー・エクスプレッション欄・音素欄には掛かりません）
・画像 ……………… png / jpg / bmp / gif / tiff / webp（透過 png 可）
・不透明度 ………… %（0: 非表示）
・表示方法 ………… はみ出さない / 画面を覆う / 原寸
・拡大率 …………… %。表示方法で決まった大きさに掛ける
・位置X / 位置Y … ノート領域の中央からのずらし(px)

◆ UTAU スタイル
・UTAUフォルダ …… UTAU 本体のフォルダ（空欄: .ust の関連付けから検出）
%VOICE% の展開・oto.ini・配色に使用
・配色 ……………… 0: UTAU の setting.ini / N: utaucolors.ini の N 番目
・選択範囲 ………… N 番目の $region をハイライト（0: なし）
・パラメータを表示 … mod / bre / flags を表示
・3拍子表示 ……… 小節を 3 拍で区切る

◆ OpenUtau スタイル
・テーマ …………… ダーク / ライト / カスタム
・テーマファイル … カスタムテーマの YAML（OpenUtau の Themes フォルダのもの）
・トラック色を使う … 鍵盤をトラック色にする（OpenUtau の同名設定と同じ）
・他トラックを薄く表示 … 他トラックのノートを半透明で重ねる

◆ エクスプレッション
・種類 1 …………… 下部に表示する種類（dyn, vel など）
空欄: プロジェクトの設定
・種類 2 …………… 灰色で重ねる種類（空欄: プロジェクトの設定）
・欄の高さ ………… px（0: 非表示）

◆ Phonemizer
・Phonemizerを実行 … OpenUtau の Phonemizer で音素化し、音素欄・
音素ごとのエクスプレッション・正確な最終ピッチを表示
・OpenUtauフォルダ … OpenUtau.exe のあるフォルダ
・音素欄の高さ …… px（0: 非表示）

[Phonemizer の実行について]
・同梱の phonemizer\UtauViewPhonemizer.exe が、指定した OpenUtau の
DLL・プラグイン・歌手・設定を読み込んで音素化します。
※ .NET 8 以降のランタイムが必要（.NET 10 版の OpenUtau には .NET 10）
・バックグラウンドで実行し、完了後のフレームから反映します。
停止中のプレビューはフレームを動かすと更新されます。
・結果は %LOCALAPPDATA%\UtauView\phonemes にキャッシュし、
ファイルや OpenUtau が変わった時だけ再実行します。
・トラックの Phonemizer が無い場合は、OpenUtau と同じく既定の
Phonemizer を使います。
・OpenUtau の設定ファイルやプロジェクトには書き込みません。


■ UST の読み取りについて
--------------------------------------------------
UTAU 本体の挙動に合わせています。
UTAU が記録する @preuttr / @overlap / @stpoint と、実際の UST
10 ファイル・3,018 音で全て一致することを確認済みです。

・先行発声・オーバーラップ
子音速度で伸縮（2^(1-Velocity/100) 倍）した後、前のノートに
収まらない分を縮める（前が休符なら全長、音符なら半分まで使える）
・STP …………… 上で縮めた分だけが STP になる（子音速度では動かない）
・音源を読めない場合 … UST の @preuttr / @overlap / @stpoint をそのまま使う
・prefix.map …… 歌詞の頭が ? なら適用しない
・休符 ………… 前後の空白を無視して判定（R、r、空など）
・エンベロープの既定値 … 0,5,35,0,100,100,0


■ 制限
--------------------------------------------------
・Phonemizer を実行しない場合、音素ごとのエクスプレッションはノート単位で
表示し、最終ピッチは先行発声分を含まずに計算します（mod+ は非対応）。
・ピッチ点の形状 sp（スプライン）は SineInOut で近似します。
・ustx を UTAU スタイルで表示すると、先行発声・オーバーラップは 0 になります。
・「背景透過」ON ではキャラクター画像を描きません。
・UTAU プラグイン用の一時ファイル（[#PREV] などを含む UST）は読めません。
